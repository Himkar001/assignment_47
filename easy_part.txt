SUB-STEP 1: STOCK DATA PREPARATION
----------------------------------------

Dataset: stock_prices.csv

Step 1: Load Data
-----------------
import pandas as pd
df = pd.read_csv("stock_prices.csv")
df.head()

Result:
- Dataset loaded successfully
- Columns include: Date, Symbol, Open, High, Low, Close, Volume

Explanation:
We load the dataset to begin preprocessing.

----------------------------------------

Step 2: Filter One Stock (Example: TCS)
----------------------------------------
stock_df = df[df['Symbol'] == 'TCS'].copy()
stock_df.sort_values('Date', inplace=True)

Result:
- Data filtered for one stock
- Sorted in chronological order

Explanation:
Time-series data must be sorted to preserve sequence.

----------------------------------------

Step 3: Convert Date Column
----------------------------------------
stock_df['Date'] = pd.to_datetime(stock_df['Date'])
stock_df.set_index('Date', inplace=True)

Result:
- Date converted to datetime
- Set as index

Explanation:
Required for time-based operations and splitting.

----------------------------------------

Step 4: Select Closing Price
----------------------------------------
data = stock_df[['Close']]

Result:
- Using only 'Close' column

Explanation:
We predict next-day closing price.

----------------------------------------

Step 5: Create Sequences (Window Size = 30)
----------------------------------------
import numpy as np

WINDOW_SIZE = 30
X, y = [], []

for i in range(len(data) - WINDOW_SIZE):
    X.append(data.iloc[i:i+WINDOW_SIZE].values)
    y.append(data.iloc[i+WINDOW_SIZE].values)

X = np.array(X)
y = np.array(y)

Result:
- X shape: (samples, 30, 1)
- y shape: (samples, 1)

Explanation:
Each input contains 30 days of data to predict the next day.

----------------------------------------

Step 6: Time-based Split
----------------------------------------
train_size = int(len(X) * 0.7)
val_size = int(len(X) * 0.15)

X_train = X[:train_size]
y_train = y[:train_size]

X_val = X[train_size:train_size+val_size]
y_val = y[train_size:train_size+val_size]

X_test = X[train_size+val_size:]
y_test = y[train_size+val_size:]

Result:
- Train, validation, and test sets created

Explanation:
Time-based split avoids data leakage.

Step 4: Feature Engineering

Message Count per Customer
--------------------------
msg_count = chat_df.groupby('customer_id').size()

Result:
- Total messages per user

Explanation:
Indicates engagement level.

----------------------------------------

Conversation Duration
----------------------
duration = chat_df.groupby('customer_id')['timestamp'].agg(['min', 'max'])
duration['duration'] = (duration['max'] - duration['min']).dt.total_seconds()

Result:
- Duration of each conversation

Explanation:
Long or short conversations may signal churn.

----------------------------------------

Response Time
----------------------
chat_df = chat_df.sort_values(['customer_id', 'timestamp'])
chat_df['response_time'] = chat_df.groupby('customer_id')['timestamp'].diff().dt.total_seconds()

Result:
- Time gap between messages

Explanation:
Higher delays may indicate dissatisfaction.
